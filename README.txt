CONTENTS
- index.html: portfolio website
- style.css: responsive styling
- script.js: mobile navigation and footer year
- assets/Priyanshu_Sarkar_Resume.pdf: downloadable resume

PREVIEW LOCALLY
1. Extract this folder.
2. Open index.html in a web browser.

PUBLISH FREE WITH GITHUB PAGES
1. Create/sign in to a GitHub account.
2. Create a new public repository named: priyanshusarkar.github.io
3. Upload the contents of this folder (index.html, style.css, script.js, assets/).
4. In repository Settings > Pages, choose Deploy from a branch, select main and /(root), then Save.
5. Wait for GitHub Pages to publish. Your site address will be:
   https://priyanshusarkar.github.io/

Before publishing, confirm that the résumé and contact details are current. The dashboard artwork on the project cards is illustrative, not a screenshot of the live dashboards. Replace it with actual screenshots if you want to show the real dashboard UI.
